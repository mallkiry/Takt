# Takt — планировщик повседневных задач
> Скачать готовое приложение для macOS или Windows можно в [Release](https://github.com/mallkiry/Takt/releases)

**Takt** — настольное приложение для планирования повседневных дел, разработанное на Python с использованием PyQt6.

В современном мире приходится совмещать учёбу, работу и личные дела. Иногда недостаточно просто записать задачи — важно ещё правильно распределить время на их выполнение.

## Цель проекта

Разработать простое и удобное приложение, которое позволит создавать задачи, отслеживать их выполнение и автоматически составлять расписание на день.

## Целевая аудитория

В первую очередь Takt рассчитан на школьников и студентов, которым приходится совмещать занятия, домашние задания и личные планы.

Также приложение может быть полезно всем, кто хочет лучше организовывать своё время.

## Возможности приложения

### Вкладка «Мой день»

- Создание, редактирование и удаление задач.
- Выбор даты, продолжительности.
- Добавление описаний с поддержкой Markdown.
- Создание собственных категорий и выбор их цвета.
- Изменение статусов выполнения задач.
- Отображение прогресса выполнения дел.
- Поздравительное окно после выполнения всех задач дня.

### Автоматическое расписание

Takt позволяет автоматически распределять невыполненные задачи на текущий день.

При составлении расписания учитываются задачи с фиксированным временем начала. Остальные дела программа распределяет последовательно.

Готовое расписание можно сохранить в TXT.

### Канбан-доски

Основная канбан-доска состоит из трёх колонок: «Нужно сделать», «В процессе» и «Готово».

Задачи можно перемещать между колонками мышью. При этом их статус автоматически обновляется во вкладке «Мой день».

Также можно создавать пользовательские доски с собственными колонками и распределять по ним существующие задачи.

### Календарь

Во встроенном календаре выделяются даты, на которые запланированы дела.

При выборе дня отображаются задачи, их время, статусы и цвета категорий.

### Системный трей

Takt может продолжать работать после закрытия главного окна.

Через значок приложения можно посмотреть сегодняшние задачи, узнать процент выполнения, открыть главное окно или добавить новую задачу.

### Настройка оформления

Пользователь может изменить основной цвет интерфейса. Цвета категорий при этом настраиваются отдельно.

## Используемые технологии

- **Python** — основной язык программирования.
- **PyQt6** — создание графического интерфейса.
- **Qt Designer** — разработка внешнего вида окон.
- **SQLite** — хранение задач и категорий.
- **Git и GitHub** — контроль версий и хранение исходного кода.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Запуск приложения и системный трей |
| `main_window.py` | Основное окно и главная логика Takt |
| `task_dialog.py` | Добавление и редактирование задач |
| `category_dialog.py` | Управление категориями |
| `schedule_dialog.py` | Автоматическое составление расписания |
| `success_dialog.py` | Поздравительное окно |
| `app/design_ui/` | Интерфейсы, созданные в Qt Designer |
| `app/pictch/` | Изображения используемые в приложении |
| `requirements.txt` | Необходимые библиотеки и их версии |


## Планы по развитию

В дальнейшем планируется добавить напоминания о задачах, автоматическое хранения и заполнение повторяющихся дел, сохранение пользовательских канбан-досок и статистику продуктивности и совершенствование автоматического расписания.
