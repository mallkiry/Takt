# Takt
***Проект по разработке приложения с использованием python и PyQt***
#### Описание проекта:
Takt - приложение для планирования повседневных задач. В современном мире жизнь наполнена большим количеством событий и задач, в большом потоке поступающей информации надо не упускать самое важное. 
#### Цель проекта:
Разработать удобное приложение, которое поможет спланировать свое время, не забывать важные задачи и успевать выполнять все в поставленные сроки.
#### Целевая аудитория:
Подростки и молодые люди (возраст от 14 до 25 лет)
#### Реализуемые фукнции:
+ Составление списка задач на день
+ Оформление всех задач на канбан доске
+ Календарь
